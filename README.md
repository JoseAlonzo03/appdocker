Descripción:



Implementación de un flujo automatizado de integración continua y despliegue utilizando Git, GitHub, GitHub Actions y Docker Hub. El proyecto permite construir automáticamente una imagen Docker cada vez que se realizan cambios en el repositorio, publicarla en Docker Hub y ejecutar la aplicación utilizando la imagen contenerizada.
